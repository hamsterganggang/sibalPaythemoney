# DEU 카르텔 자금 현황

시즌별 납부/미납 현황을 보여주는 GitHub Pages(Jekyll) 사이트.

| 시즌 | 기간 | 월 납입금 |
|---|---|---|
| 시즌 1 | 2026.04 ~ 2026.08 (종료) | 10만원 |
| 시즌 2 | 2026.12 ~ 진행 중 | 5만원 |

## 현황 업데이트 방법

`_data/payments.yml` 파일만 수정하면 됩니다.

- `"O"` → 납부 완료 (초록 ✓)
- `""` (빈칸) → 미납 (빨강). 아직 오지 않은 달은 자동으로 `예정`(회색) 표시
- 그 외 텍스트 (예: `"2.5만원"`) → 빨간 칸에 해당 텍스트 표시 (미납으로 집계)

새 달을 추가하려면 해당 시즌의 `months`에 `"2027-01"`처럼 `YYYY-MM` 형식으로 추가하고,
각 사람의 `status`에도 값을 하나씩 추가하세요.

적립액 / 미납액 / 납부율은 시즌별 `fee`(월 납입금) 기준으로 자동 계산됩니다.
"예정" 판정은 사이트가 빌드된 날짜 기준이라, 커밋/푸시할 때마다 갱신됩니다.

수정 후 커밋/푸시하면 GitHub Pages가 자동으로 사이트를 다시 빌드합니다. (반영까지 1~2분)

```
git add _data/payments.yml
git commit -m "12월 납부 현황 업데이트"
git push
```
